# HÖHENBERGSTEIGEN V6 — Expeditionstagebuch

Komplett eigenständige Landingpage. Keine KI-generierten Bilder: die Dateien in `assets/` sind die vorhandenen Originalbilder.

## Deploy
Alle Dateien dieses Ordners ins GitHub-Repository legen. Für eine statische Render-Site ist kein Build-Schritt nötig; Publish Directory: `.`

## Bildtausch
Bilder können später einzeln in `assets/` ersetzt werden. Entweder denselben Dateinamen verwenden oder den Pfad in `index.html` ändern.

## Wichtig
Das Logo wird hier bewusst nicht als erfundenes KI-Symbol nachgebaut. Im Header steht eine typografische Wortmarke. Sobald die originale Logo-Datei (PNG/SVG) vorhanden ist, kann sie 1:1 eingesetzt werden.
