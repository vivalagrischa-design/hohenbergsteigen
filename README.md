# HÖHENBERGSTEIGEN V6
Komplett neu codierte statische Landingpage.

## Deploy
Alle Dateien ins GitHub-Repository-Root legen. Für Render: Static Site, Publish Directory `.`.

## Bilder austauschen
Alle Bilder liegen unter `assets/`. In `index.html` kann jedes Bild über `src="assets/..."` einzeln ersetzt werden.

## Wichtig
Die vorhandenen Bilder sind Platzhalter aus den bereits gelieferten Originalfotos. Keine KI-generierten Bilder sind als Website-Assets eingebaut. `V6-reference.png` ist nur die Designreferenz und wird von der Website nicht geladen.
