# HÖHENBERGSTEIGEN Website

Statische, responsive Website ohne Shop-Modul. Reisebereiche öffnen als Modal/Overlay statt auf separaten Unterseiten.

## Lokal starten
Einfach `index.html` im Browser öffnen oder z.B. `python3 -m http.server 8080` ausführen.

## Render
- New > Static Site
- Repository verbinden
- Build Command: leer lassen
- Publish Directory: `.`

## Bilder
Die Website verwendet das vom Nutzer bereitgestellte HÖHENBERGSTEIGEN-Logo lokal. Bestehende HÖHENBERGSTEIGEN-Fotos werden in dieser ersten Version direkt von der bisherigen Website referenziert. Vor Abschaltung der alten WordPress-Seite sollten die Originalbilder in `/assets` übernommen und die Bildpfade lokal umgestellt werden.
