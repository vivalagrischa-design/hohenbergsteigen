# HÖHENBERGSTEIGEN V5

Static site: `index.html`, `styles.css`, `script.js`, `assets/`.

## Deploy
1. Inhalt dieses Ordners ins Root des GitHub-Repos `vivalagrischa-design/hohenbergsteigen` kopieren.
2. Commit auf `main`.
3. Render Static Site deployed automatisch; Publish Directory bleibt `.`.
4. Produktions-DNS noch nicht umstellen, bis die Vorschau freigegeben ist.

V5 verwendet die bereitgestellten Originalbilder und einen zurückhaltend vereinheitlichten dokumentarischen Bildlook.
